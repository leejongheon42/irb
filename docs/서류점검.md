# 서류 품질 점검과 자동 교정

IRB에 제출하기 전에 서류를 같은 기준으로 점검하고, 고칠 수 있는 부분은 원본 서식을 유지한 채 고쳐 돌려줍니다.
교차 문서 불일치·버전 오류·필수 기재사항 누락은 IRB 보완 요청의 가장 흔한 원인입니다.

## 1. 사용 방법

| 방법 | 화면 | 특징 |
|---|---|---|
| 과제 서류 점검 | 과제 › 제출 서류 패키지 › 서류 점검 (또는 자동 완성 실행 시 자동) | 서류함의 현행본 전체 + **과제 입력값과 대조**, 교정본을 새 버전으로 저장 |
| 빠른 점검 | 서류 품질 점검 (`/qc`) | 과제 없이 파일만 올려 점검. 과제를 선택하면 과제 정보와도 대조 |
| 샘플 체험 | `/qc` › 샘플 서류로 체험 | 의도적으로 문제를 넣은 계획서 v3.0 + 동의서 |

결과 화면에는 다음이 나옵니다.
- 확정 점수, 예상 점수, 검사 완료율 및 FAIL/HOLD/REVISE/MINOR/PASS 상태
- Critical·Major·Minor 건수
- 3단계 스캔 상태
- 서류별 이슈: 근거 문장과 권고, 자동 교정 문구(삭제 → 교정)

## 2. 3단계 스캔

| 단계 | 방식 | 점검 |
|---|---|---|
| Phase 1 규칙 기반 | 결정론적(같은 입력 → 같은 결과) | 필수 기재사항, 버전, 미기입·자리표시자, 실제 개인정보, 규제(보관 기간·동의 계획), 용어 통일, 교차 문서·과제 정보 대조 |
| Phase 2 AI 심층(선택) | Claude, 개인정보 마스킹 후 전송, 이미 찾은 이슈는 중복 지적하지 않음 | 문맥 모순, 위험 설명 축소, 규제 비준수, 가독성, 의학 용어·용량 오기 |
| Phase 3 오탈자·숫자 | 결정론적 | 오탈자 사전, 단어 반복, 존재하지 않는 날짜, 기간 역전, 한 문서 안의 서로 다른 용량·방문·기간 표기 |

AI 지적의 인용은 해당 문서 원문과 공백을 정규화하여 대조합니다. 인용이 없거나 원문에서 확인되지 않으면 '인용 미확인 · 감점 제외'로 표시하고 자동 교정을 제공하지 않습니다. 인용이 확인된 경우에도 교정할 원문이 그대로 있을 때만 자동 교정 대상이 됩니다. 인용의 존재 확인이 지적 내용의 타당성까지 보장하지는 않습니다. AI가 꺼져 있으면 Phase 1·3만 실행합니다.

## 3. 판정

- 감점: Critical −15, Major −7, Minor −2 (100점 시작)
- 검토자가 확정한 미해결 오류만 감점합니다. AI 후보, 확인 필요 및 개선 의견은 감점하지 않습니다.
- 확정 Critical이 있으면 FAIL, 남은 확인 항목이나 후보가 있으면 HOLD입니다. 그 외에는 확정 Major가 있으면 REVISE, 확정 Minor가 있으면 MINOR, 모두 해소되면 PASS입니다.
- 값은 `criteria.yaml`의 `scoring`에서 바꿉니다.
- 인용 미확인 AI 이슈와 `unchecked` 항목은 감점·심각도 집계에서 제외합니다.

## 4. 교차 대조 항목

추출한 값을 같은 범위의 서류끼리 대조합니다. 현재 제출 묶음의 문서 중 사용자가 기준값을 지정한 뒤에만 교정안을 만듭니다. 과제 입력값에 대한 별도 대조는 기관 설정에서 끌 수 있습니다.

| 항목 | 중요도 | 인식 예 |
|---|---|---|
| 연구대상자 수 | Major | "목표 연구대상자 수는 총 1,200명", "기관별 대상자 수: 40명" |
| 시험약 명칭, 투여 용량·빈도·경로 | Critical | "시험약: A", "1일 1회 100mg 경구 투여" |
| 방문 횟수 | Major | "총 8회 방문", "필요 시 추가 방문은 2회" |
| 참여·시험 기간 및 연구 기간 | Major | "시험 기간은 총 12주", "연구 기간: 2026.12.01 ~ 2027.11.30" |
| 연구 제목·번호·책임연구자·수행기관, 자료 수집·보관 기간 | Major | "연구번호: QC-31", "수행기관: 가상병원" |
| 선정 연령, 검체 채취량, 가명·익명 처리 수준, 비용·보상, 문의처 | Major | "선정 연령: 만 18세 이상 65세 미만", "검체 채취량: 5mL", "교통비 2만원" |

단위나 비교 범위가 다르면 확인 필요로 두고, 직접 확인한 결과와 사유를 저장한 뒤 오류를 별도로 확정합니다. 같은 사실이 과제 입력값과 문서에서 함께 다르면 하나의 이슈로 검토합니다. 근거가 검수되지 않은 필수 기재사항은 후보로 표시합니다.

교정 문구는 원문 형식을 유지합니다. 예를 들어 `2026년 1월 5일 ~ …`은 `년·월·일` 형식 그대로, `1,500명`은 천 단위 구분 기호를 유지해서 고칩니다.
군별 인원으로 합계를 추출한 경우 군 배분을 임의로 바꾸지 않도록 자동 치환을 제공하지 않습니다. 명시된 총인원이 있으면 군별 합산보다 우선합니다. '3년이 지나면 폐기' 같은 보관·폐기 표현도 인식합니다.

## 5. 자동 교정

- **DOCX**: 두 가지 파일을 만듭니다. 표·머리글·바닥글·각주와 글자 서식은 그대로 둡니다.
  - **변경 추적본**: `w:del`·`w:ins`로 바꾼 곳을 표시합니다. Word나 한컴오피스에서 변경 내용을 확인한 뒤 수락할 수 있습니다.
  - **수정 완료본**: 고친 곳에 노란 형광펜을 칩니다.
  - **글꼴 통일**(선택): 모든 글자의 한글·영문 글꼴을 지정한 글꼴로 맞춥니다.
- **HWPX**: 문단(`hp:p`) 안에서 텍스트만 바꿉니다. 변경 추적은 지원하지 않습니다.
- **PDF·HWP(구형)**: 자동 교정할 수 없으므로 원본(DOCX·HWPX)을 올려야 합니다.
- **자동으로 쓰지 않는 것**: 필수 기재사항 누락처럼 내용을 새로 써야 하는 항목은 연구자가 직접 작성해야 합니다.
- **과제 서류에 적용한 경우**: 수정 완료본이 새 버전으로 저장됩니다. '다시 점검'으로 확인하십시오.

## 6. 점검 기준 수정 (`irb_automation/qc/criteria.yaml`)

기관용 사본을 만들어 `IRB_QC_CRITERIA_PATH`로 지정합니다. 파일을 저장하면 다음 점검부터 반영됩니다.

| 키 | 내용 |
|---|---|
| `required.<서류 종류>` | 필수 기재사항: `any`(하나라도) / `all`(모두) 키워드, `re:` 정규식, `when`(children·waiver·obtain·identifiable·prospective·ai_ml·external_transfer 조건) |
| `required_min_chars` / 항목의 `min_chars` | 후보 본문 최소 길이(공백 제외, 기본 15자) |
| 항목의 `must` / `reject` | 반드시 있어야 하는 표현 / 있으면 충족으로 인정하지 않는 표현 |
| 항목의 `structured` | 기간·인원·연락처·서명처럼 서술문이 아닌 값/양식 항목 |
| 항목의 `rubric` / `basis` | 내용 미흡 시 작성 안내 / 기관이 원문 대조한 근거(미검수 항목은 비움) |
| `terminology` | 표준 용어와 변형 목록 |
| `typos` | 틀린 표현 → 바른 표현 |
| `placeholders` | 미기입 표지 |
| `cross_fields` | 교차 대조 항목과 화면 표시 이름 |
| `regulatory.min_retention_years` | 최소 보관 기간 |
| `scoring` | 등급별 감점 및 확정 Critical의 FAIL 여부 |

## 7. 한계

규칙의 등급, 기간·용량 호환 그룹, 플래그별 점검 방식은 `qc/rules.yaml`에 있습니다. 공용 IRB 묶음과 신청 경로 조건은 `qc/required_docs.yaml`에 있습니다. 묶음 규칙의 `when`은 AND이며 `human`, `specimen`, `new`, `exemption`, `collect`, `survey` 등의 신청 경로 값을 사용합니다. 이 파일들만 대조할 때는 제출 묶음 검사를 끌 수 있습니다.

- 값 추출은 한국어 IRB 서류의 일반적인 표현 패턴을 기준으로 합니다. 표현이 특이하면 놓칠 수 있고, AI 단계를 켜면 보완됩니다.
- 스캔본(이미지 PDF)은 텍스트가 없어 점검할 수 없습니다(AI 문서 인식 OCR 필요).
- 필수 기재사항은 후보 문단의 분량·서술 여부·필수 표현으로 판정합니다. 후보가 없으면 `missing`, 내용이 부족하면 `partial`입니다. 내용 미흡도 기존 심각도를 유지합니다. 의미 전체를 이해하는 판정은 아니므로 연구자가 확인해야 합니다.
- 제목 탐지는 평문 기반이며 DOCX 제목 스타일·표 구조를 직접 해석하지 않습니다.
- 신청 경로는 공용 IRB 제출 묶음 기준에 반영됩니다. 권고 서식의 절 구성 대조와 수정 전후 이슈 비교는 아직 제공하지 않습니다.

## 8. 반복 평가

`python -m irb_automation qc-eval --json qc-eval.json`으로 합성 사실 추출 46건과 별도의 규칙 판정 사례를 평가합니다. AI나 DB 없이 3회 반복하며, 추출 재현율·정밀도 90% 미만, 재현성 100% 미만 또는 판정 기대값 불충족·금지된 지적 발생 시 종료코드 1을 반환합니다.

이 수치는 작은 회귀 세트에 대한 결과입니다. 실제 IRB 서류 검출률·전체 규칙 오탐률·교정 정확도·AI 성능을 뜻하지 않습니다. 계획서 W1의 실제 보완 사례 및 문서 유형별 평가 세트는 추가 구축이 필요합니다.

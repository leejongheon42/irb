# 시장 조사 및 기능 분석 (v2.0 고도화 근거)

조사일: 2026-11-05 · 범위: 상용 e-IRB, 연구데이터 접근·반출 관리(TRE), 국내 제도(생명윤리법 평가·인증, 가명정보 지침), AI 활용 동향

> 공개 자료 기반 조사입니다. 벤더 자료와 순위 사이트의 수치·우열 평가는 신뢰도가 낮아 기능 범주를 파악하는 용도로만 사용했습니다.
> 법령·지침은 개정 가능성이 있으므로 최종 판단은 원문과 기관 법무·개인정보보호 부서 검토를 거쳐야 합니다.

## 2. 격차 분석 → v2.0 반영 내역

| 필요 기능 | v1.0 | v2.0 구현 |
|---|---|---|
| 위원회 회의 운영 | 결정 입력만 | **회의 생성·안건 자동 구성**(정규심의=심의 안건, 신속·면제·종료=보고 안건), **출석·의사정족수 판정**(재적 과반, 비과학계 위원 출석 등 규칙화), **이해상충 자동 회피**(연구팀 소속 위원), **표결·과반 판정 → 결정·통지서 자동 발행**, **회의록 자동 작성** |
| 위원회 구성 요건 | 없음 | 생명윤리법 제11조 요건 점검(5인 이상, 양성, 사회적·윤리적 위원, 외부위원, 임기·교육) |
| 전자서명 | 없음 | 제출 시 **연구자 서약 + 비밀번호 재인증 + 내용 해시(SHA-256)**, 결정 시 서명 기록, 통지서에 서명 해시 표기 |
| 보완 요청 관리 | 자유 텍스트 1건 | 사전검토 지적사항을 골라 **항목별 보완 요청**, 연구자 **항목별 답변**(미답변 시 재제출 차단), 위원에게 답변 대비 표시 |
| 변경 대비표 | 없음 | 제출본 간 **자동 비교**(핵심 항목 강조), 출력용 대비표, 변경 대비표 서식 자동 작성 |
| 서류 작성 부담 | 업로드만 | **심의의뢰서·면제 신청서·동의면제 사유서·가명처리 계획서(항목별 처리 방법 자동 제안)·자료수집 항목표·보안서약서·변경 대비표·참여기관 목록 자동 작성 및 첨부** |
| 연구진 자격 | 책임자만 | **공동연구자 전원** 교육 이수 확인 |
| 다기관/위임심의 | 없음 | 다기관 여부, 심의 방식(단독/대표 IRB/타기관 IRB 인정), 참여기관, 대표 IRB → 필수 서류·검토 의견 규칙 |
| 결과 반출(airlock) | 없음 | 결과표 업로드 → **소규모 셀·식별자·자유기술·개인 단위 자료 자동 점검**, **자동 억제본** 생성, 데이터관리자 승인(원본/억제본/반려), 승인본만 다운로드 |
| DRB 적정성 검토 | 자동 판정만 | **처리자와 분리된 위원의 적정성 승인**이 있어야 제공(재처리 시 재검토) |
| 가명정보 처리기록 | 감사 로그 | **처리기록 대장 자동 작성**(개인정보 보호법 제28조의4: 목적·항목·방법·제공받는 자·일시) + CSV |

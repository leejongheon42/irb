## 검토 피드백 반영 (2026-11-14)

기준: [서류 점검 파이프라인 구현 검토 결과](서류점검_파이프라인_검토결과.md)

| 항목 | 수정 및 확인 |
|---|---|
| F-01~F-03 | 확인 필요 항목의 사유별 답변을 저장하고 별도로 확정합니다. 근거 미검수 필수 항목은 비감점 후보로 표시합니다. 일부 파일만 대조하는 범위, 범위 제외 또는 추후 제출을 선택할 수 있습니다. 연구 제목·번호·책임자가 모두 다른 경우 혼입 후보를 냅니다. |
| F-04~F-10, F-17 | 시험/참여 기간과 다른 단위의 기간을 확인 대상으로 올립니다. 1회량과 하루 총량은 환산 근거가 있을 때 비교하며 mg/kg의 분모를 보존합니다. 복수 약물, 필수/선택 방문 및 개정 이력의 재현 사례를 검사합니다. 약물 투여 없음과 검체 연구 유형은 불충분한 문장으로 확정하지 않습니다. |
| F-11~F-14 | 문서와 과제의 같은 대상자 수 차이를 한 번만 집계합니다. 정상·비적용 검사 단위를 보존하고 미검토 후보를 완료율에서 제외합니다. 위원회, 다기관, 박사학위 학생, 취약 대상 여부를 입력하고 같은 파일을 다시 점검할 수 있습니다. |
| F-15~F-20 | 동일 규칙·플래그와 인용이 겹치는 AI 지적은 중복 집계하지 않습니다. AI 인용은 실제 전달된 마스킹 본문에 대조합니다. 점검 방식 표, 별도 날짜 값 오류, 판정 평가와 금지 결과 검사를 추가했습니다. |

권고 서식·지침 원문 대조는 미완료입니다. 개정 이력의 위치 분류는 평문과 DOCX 머리글·바닥글 묶음을 이용하며, 모든 기관의 제목·표 구조를 해석하지는 않습니다. 플래그별 점검 방식 표는 탐지 경로를 안내하며 모든 범위에서 검사를 수행했다는 뜻은 아닙니다.

피드백 반영 후 전체 pytest 208건과 Ruff 검사를 통과했습니다. `qc-eval`은 합성 추출 46건(기대 사실 45/45, 오탐 0)과 규칙 판정 15건(실패 0, 금지 지적 0)을 통과했습니다. HTTP 테스트에서 확인 필요 직행 확정 거절, 확인 결과 저장 후 85점·FAIL, 같은 파일의 조건 수정 후 PASS를 검증했습니다.

아래는 최초 구현 기록입니다.

업로드한 문서 묶음에 신청 경로를 적용하고, 비교 근거를 확인한 뒤 검토자가 점수를 확정할 수 있도록 기존 QC를 개선했습니다. 이 문서는 실제 반영과 남은 요구사항을 구분합니다.

## 반영한 동작

| 영역 | 변경 내용 |
|---|---|
| 신청 경로·제출 묶음 | 업로드 화면에 연구 유형, 심의 신청, 자료 확보, 동의, 연구 방법, 약물 투여, 방문 일정을 추가했습니다. 직접 입력, 과제 기록, 문서에서 판단한 값의 출처를 저장합니다. 공용 IRB 카탈로그와 기관 체크리스트를 구분하고, 파일 미제공·중복 역할·판독 실패를 확인 대상으로 남깁니다. 지정된 자료는 e-IRB 입력으로 제출했다는 응답을 기록할 수 있습니다. |
| 사실 추출·교차 대조 | 전체/기관별/군별 인원, 필수/선택 방문, 기간 종류 및 1회/1일 용량을 분리합니다. 질량 환산, 경구 경로 약어, 문의 번호 표기를 정규화합니다. 문서별 원문과 값을 한 이슈에 모으고 기준값을 선택할 때만 교정안을 만듭니다. |
| 버전·수치·필수 내용 | 개정 이력의 과거 버전을 현재 버전으로 보지 않습니다. 근거가 확인되지 않은 필수 항목은 확인 필요로 표시하고 철회 권리는 별도 검사합니다. 이상반응/부작용을 자동으로 통일하지 않으며, 같은 문장에 명시된 군별 인원 또는 투여량 합계를 확인합니다. |
| 규칙·검토·점수 | 레지스트리에 M01~M10 플래그 51개와 E01~E10을 등록했습니다. 검토 확정, 오탐 철회, 확인 필요 전환, 경미한 잔여 이슈 수용, 규칙 후보 일괄 확정과 감사 기록을 추가했습니다. 확정된 고유 미해결 이슈에만 15/7/2점 감점을 적용하고, 80점 기준을 제거했습니다. |
| 결과·내려받기 | 결과 화면에 신청 조건, 문서별 대조값, 제출 구성, 확정·예상 점수와 완료율을 표시하고 DOCX 보고서를 내려받을 수 있습니다. 기존 수정 완료본·변경 추적본 다운로드를 유지했습니다. |
| 선택 AI | 본문·파일 표시명·과제 요약·기존 이슈를 전송 전에 마스킹합니다. 교차 지적은 서로 다른 두 문서의 인용을 검증합니다. AI 결과는 후보로 저장되며 자동 교정이나 즉시 감점으로 이어지지 않습니다. |

## 검증

- 전체 pytest: 203건 통과. 신규 SQLite 컬럼 추가 및 기존 판정 보존도 확인했습니다.
- 전체 Ruff 검사: 통과.
- 합성 사실 추출 평가: 기존 36건에서 46건으로 확장. 기대 사실 45/45 검출, 오탐 0건, 정밀도·재현율·3회 재현성 100%. 이 수치는 합성 사실 추출에 한정합니다.
- HTTP 검증: 샘플 제출, 결과 화면, 기준값 선택, 규칙 후보 일괄 확정, Word 보고서 열기, 교정 파일 받기 및 타 사용자 접근 차단을 합성 자료로 확인했습니다.
- 커밋과 배포는 하지 않았습니다.

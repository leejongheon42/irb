# AI가 IRB 제출 서류에서 검토하는 항목

서류점검에서 AI는 두 번 쓰인다. **심층 분석**에서는 연구계획서·동의서·심의신청서 등을 함께 읽고, 문맥을 살펴야 발견할 수 있는 누락이나 모순을 찾는다. **최종 재검토**에서는 규칙이나 AI가 이미 지적한 항목을 원문과 다시 대조한다. 이때 원문 근거로 오탐이 확인되면 처음 등급이 Critical이어도 해당 항목은 통과한다.

## 심층 분석에서 보는 내용

아래 예시는 어떤 차이를 살펴보는지 설명하기 위한 것이다. 실제 검토 범위는 제출한 서류와 그 안에서 읽어 낸 텍스트에 따라 달라진다.

| 검토 항목 | AI가 확인하는 내용 | 예시 |
| --- | --- | --- |
| 연구와 대상자 | 서류에 적힌 연구명·기관, 모집 인원과 산출 근거, 선정·제외 기준이 서로 맞는지 살핀다. 인원은 전체·하위집단, 모집·분석 중 어느 집단의 수인지 구분한다. | 계획서의 모집 목표 120명과 신청서의 최종 분석 예상 인원 100명이 서로 다른 집단을 가리키는가? |
| 기간과 방문 일정 | 전체 연구 기간, 자료 수집 기간, 한 사람의 참여 기간을 구분한다. 방문 시점·횟수·절차와 필수·선택 여부도 대조한다. | 계획서에는 추적 방문이 필수인데 동의서에는 희망자만 방문한다고 적었는가? |
| 약물과 투여 방법 | 시험약과 대조약의 역할, 약물명과 코드의 대응, 용량·단위·횟수·경로가 투여 단계별로 일관되는지 본다. | 계획서의 첫 투여량과 동의서의 유지 투여량을 같은 단계의 값으로 비교하고 있는가? |
| 연구 절차·검체·위험 | 계획한 검사, 검체 채취, 방문 부담과 예상 위험이 대상자 설명에도 반영됐는지 확인한다. | 계획서에는 추가 채혈이 있는데 설명문에는 기존 진료자료만 이용한다고 적었는가? |
| 동의와 대상자 권리 | 동의 취득 또는 면제 신청 경로, 면제 신청 사유, 자발적 참여와 철회 권리, 비용·보상·문의처에 관한 설명을 살핀다. | 동의서 앞부분에는 언제든 철회할 수 있다고 하고 뒷부분에는 연구 종료 전 철회가 불가능하다고 적었는가? |
| 개인정보와 자료 관리 | 수집 항목, 식별 가능성, 가명처리, 자료 이용·제공, 보관 기간과 폐기 방법이 문서 안팎에서 일관되는지 확인한다. | 본문은 익명 설문이라고 설명하지만 수집 항목 표에는 환자등록번호가 있는가? |
| 표·본문의 수치와 조건 | 표와 본문에서 반복되는 수치·단위, 범위의 경계, 조건과 예외의 뜻을 대조한다. | 본문은 만 19세 이상을 포함하는데 표에는 만 19세 초과라고 적었는가? |
| 용어·오기·가독성 | 약어를 처음 쓸 때 설명했는지, 같은 약어를 여러 뜻으로 쓰는지, 의학용어·기호에 오기가 있는지 본다. 동의서에서 어려운 문장이나 효과를 과장한 표현도 찾는다. | 대상자가 읽는 설명문에서 전문용어를 풀이하지 않았거나 예상 이익을 보장된 효과처럼 표현했는가? |

AI는 관련 문서의 구절을 인용해 지적 사유와 수정 제안을 낸다. 문서 간 모순을 지적하려면 서로 다른 문서의 근거가 필요하다. 시스템은 인용이 실제 텍스트에 있는지 검사한다. 규칙이 이미 찾은 문제를 AI도 같은 근거로 지적하면 기존 항목에 근거를 보탠다. 같은 문단에서도 수정할 내용이 서로 다르면 별개로 다룬다.

## 최종 재검토에서 판정하는 방법

최종 재검토 대상은 아직 판정이 끝나지 않은 규칙 지적과 원문 인용이 검증된 AI 지적이다. 단순 개선 권고는 대상에서 제외한다. 필수 기재사항은 **그 내용이 있어야 하는 문서**에서 찾는다. 표, 다른 절, 뜻이 같은 표현도 근거로 쓸 수 있다.

| 원문을 확인한 결과 | 시스템 처리 |
| --- | --- |
| **문제없음**. 지정된 문서에 요구 내용이 실제로 있거나, 규칙이 서로 다른 범위의 값을 비교했다. | AI가 이유를 제시하고 대상 문서마다 인용이 검증되면 **해당 항목을 통과**시킨다. Critical·Major·Minor 모두 감점과 ‘확인 필요’ 건수에서 제외한다. |
| **지적이 타당함**. 항목 제목만 있고 내용은 비었거나, 같은 집단의 같은 값이 실제로 다르다. | 기존 지적을 유지하고 해당 항목의 채점 기준을 적용한다. |
| **원문만으로 판단하기 어려움**. 어느 집단을 뜻하는지 불분명하거나 외부 확인이 필요하다. | 필수 기재사항이나 문서 간 비교 등에서 AI가 불확실한 이유를 제시하면 조건에 따라 ‘확인 필요’로 돌린다. AI가 오탐이라고 답했어도 인용이나 이유가 부족하면 기존 판정을 유지한다. |

예를 들어 규칙이 ‘대상자 수 산출 근거 누락’을 지적했어도, 계획서 표에서 목표 인원과 산출 근거를 함께 확인하면 그 항목은 통과한다. 반면 계획서와 신청서가 **같은 전체 모집 인원**을 각각 80명과 90명으로 명시하고 AI도 그 두 수치를 그대로 인용했다면, ‘두 수가 같다’는 AI 답변으로 기존 불일치를 철회할 수 없다. 전체 서류의 통과 여부는 나머지 항목까지 반영해 계산한다.

## AI가 읽는 자료와 검토 범위

- **입력 자료** — 각 문서에서 추출한 텍스트, 문서 종류와 파일명, 규칙이 먼저 찾은 지적 목록을 사용한다. 과제에 연결된 점검이면 연구 유형·기간·대상자 수·동의 방식 등 등록 정보의 요약도 심층 분석에 전달한다. 전송 전 전화번호·이메일 등 탐지된 개인정보 패턴을 마스킹한다.
- **규칙과 외부 확인** — 파일명과 본문의 버전 대조, 제출 묶음 구성, 등록된 과제 값 대조는 규칙이 먼저 수행한다. AI는 서류에서 동의 면제 사유나 개인정보 처리 설명을 검토할 수 있다. 실제 e-IRB 제출·승인 여부나 적용 법령은 본문만으로 확정할 수 없다.
- **판독과 분량** — 본문을 읽을 수 있는 문서만 AI에 전달한다. 읽을 수 있는 본문 합계가 60만 자를 넘으면 심층 분석은 가능한 문서끼리 나누어 수행하며, 개별 한도를 넘은 문서는 제외한다. 최종 재검토는 전체 본문이 이 한도를 넘으면 건너뛴다. 호출 실패나 응답 누락으로 재검토하지 못한 항목은 기존 판정을 유지한다.

# 기관 서식(DOCX·HWPX) 템플릿

병원마다 IRB 서식(심의의뢰서, 동의 면제 사유서 등)의 모양이 다릅니다. 이 기능은 기관이 이미 쓰고 있는
**원본 서식 파일을 그대로 올리고**, 안에 표시한 자리표시자를 과제 정보로 채워 문서를 자동 작성합니다.

- 관리 화면: `/admin/templates` (시스템관리자·IRB 간사)
- 서식 자료실: `/doc-templates` (전체 사용자 — 빈 서식, 내 과제로 채운 서식 내려받기)
- 과제 화면 → 서류 탭의 '서류 자동 작성' 미리보기/첨부는 활성 기관 서식이 있으면 그 서식을 씁니다.

## 1. 진행 순서

1. 워드/한글에서 서식의 빈칸에 `{{연구제목}}`처럼 자리표시자를 적고 DOCX 또는 HWPX로 저장합니다.
2. `/admin/templates`에서 서류 종류를 고르고 업로드합니다. 형식을 검사(ZIP 시그니처·필수 항목)하고 자리표시자를 자동으로 찾습니다.
3. 매핑 표에서 자동 추천(필드명 → 별칭 사전 → 표시명 → 문자열 유사도)을 확인·수정하고 저장합니다.
   서명처럼 손으로 쓸 칸은 '빈칸으로 비움' 또는 '자리표시자 그대로 둠'을 고릅니다.
4. 실제 과제로 '채워보기'로 결과를 확인한 뒤 **활성화**합니다. 미매핑 자리표시자가 있으면 활성화할 수 없습니다.
5. 서류 종류마다 활성 서식은 1개이며, 새로 올리면 버전이 올라가고 이전 버전은 이력으로 남습니다(감사 로그 기록).

`샘플 서식 만들기` 버튼은 서로 다른 병원 양식 2종(가나다대학교병원 심의의뢰서 `{{ }}` 문법,
라마바의료원 동의 면제 사유서 `[[ ]]`·`« »`·편지 병합 필드)을 즉석 생성해 등록합니다.

## 2. 자리표시자 문법

| 구분자 | 예 |
|---|---|
| `{{이름}}` | `{{연구제목}}` |
| `«이름»` | 워드 편지 병합 표시. MERGEFIELD 필드도 자동으로 `«이름»`으로 풀어 처리 |
| `[[이름]]` | `[[과제명]]` |

구분자 안: `[#|/]이름[(=|~)값][|형식]`

- **값**: `{{연구책임자}}` — 이름은 한글 가능, 매핑으로 표준 필드에 연결. 이름이 필드 경로(`title`, `profile.irb_name` 등)와 같으면 매핑 없이 연결됩니다.
- **형식**: `{{작성일|YYYY년 MM월 DD일}}`, `{{수집항목|줄바꿈}}`
  - 날짜: `YYYY` `YY` `MM` `M` `DD` `D` 조합, `한글`(=YYYY년 MM월 DD일)
  - 목록: 기본 쉼표, `줄바꿈`/`lines`, `글머리`/`bullets`, `번호`/`numbered`
  - 예/아니오: 기본 예/아니오, `check`(■/□), `ox`, `유무`, `있음없음`
  - 숫자: 기본 천 단위 쉼표, `raw`
  - 매핑에서 `경로|형식`으로 기본 형식을 지정할 수도 있습니다(자리표시자의 형식이 우선).
- **비교(체크박스)**: `{{동의방식=waiver}}` → 같으면 ■, 아니면 □. 목록 필드는 포함 여부(`{{데이터출처=cdw}}`), `~`는 부분 일치. 카탈로그 코드와 표시명 모두 비교합니다.
- **반복**: 아래 3절.

## 3. 반복 규칙(표 행·문단)

- 표의 한 행 어디든 `{{#목록}}` 표식이 있으면 그 **행을 목록 항목 수만큼 복제**합니다.
- 표 밖 문단에 `{{#목록}}`이 있으면 그 문단을, 같은 부모 안 뒤쪽 문단에 `{{/목록}}`이 있으면 거기까지의 **블록을** 복제합니다.
- 반복 단위 안에서 쓰는 이름(매핑 불필요):
  - `{{item}}` 항목 값, `{{item.속성}}` 항목의 속성, `{{no}}`(또는 `순번`/`번호`) 1부터 순번
  - 한글 속성 별칭: 성명/이름→name, 소속/부서→department, 역할/구분→role, 이메일/연락처→email, 교육만료일→training_expires_on, 분류→category, 처리방법→handling
- 빈 목록이면 빈 행(문단) 1개를 남깁니다. 표식 자체는 지워집니다.

목록 필드: `team`(name, department, email, role, training_expires_on), `data_items`(문자열),
`data_item_rows`(name, type, category, handling), `identifier_rows`(name, handling), `data_sources`,
`identifiers_collected`, `participating_sites`, `waiver_impracticable_reasons` 등.

```
| 구분              | 성명          | 소속            |
| {{#연구진}}{{item.역할}} | {{item.성명}} | {{item.소속}} |
```

## 4. 필드

관리 화면의 드롭다운이 전체 목록(그룹·설명)입니다. 주요 경로:

- 기본: `title`, `protocol_no`, `version`, `study_type`, `study_period`, `funding_text` …
- 연구진: `pi_name`, `pi_department`, `pi_email`, `co_investigators`, `team`
- 내용·데이터: `objectives`, `methods`, `expected_subjects_text`, `data_period`, `data_items`, `identifiers_label`, `sensitive_label`
- 개인정보: `deid_level`, `storage_location`, `retention_text`, `destruction_method`
- 동의: `consent_plan`, `consent_text`, `waiver_impracticable_detail`, `coi_text`
- 심의: `review_type_label`, `risk_score`, `risk_level_label`(제출 후), `auto.review_type_label`·`auto.risk_score`(현재 내용으로 즉시 계산)
- 날짜: `today`, `year`
- `profile.*`: 기관 정보(기관 프로필 기능이 있으면 그 값, 없으면 환경 설정의 기관명·위원회명)
- `custom.<key>`: 기관 추가 항목(과제의 custom_fields)
- 카탈로그 필드는 표시명으로 채워지고, 코드가 필요하면 `<필드>.code`

## 5. 형식별 처리

- **DOCX**: 본문·표(중첩 포함)·머리글·바닥글·각주. 워드가 자리표시자를 여러 run으로 쪼개 저장해도 문단 단위로 이어 찾고, **첫 run의 서식(굵게·글꼴 등)을 유지**해 기록합니다. 값의 줄바꿈은 줄바꿈(w:br)으로.
- **HWPX**: `Contents/section*.xml`의 `hp:p`/`hp:t`(머리글·바닥글·표 셀 포함). 같은 문단 안 run 분할을 결합 처리, 줄바꿈은 `hp:lineBreak`. 원본 ZIP의 항목 순서·압축 방식을 보존하고 `mimetype`은 첫 항목·무압축으로 기록합니다. XML은 외부 엔티티를 해석하지 않습니다.
- **HWP(바이너리)·DOC**: 지원하지 않습니다. 한글/워드에서 HWPX·DOCX로 저장해 올려 주십시오.
- **PDF**: 문서 변환 모듈(`docproc.convert.to_pdf`)이 설치되어 있으면 'PDF로 받기'가 나타납니다.
- 제한: 20MB, 압축 해제 200MB·3000 항목 이하.

## 6. 한계

- 서로 다른 문단에 걸친 자리표시자(문단 중간 줄바꿈)는 인식하지 않습니다.
- 반복 블록은 같은 부모(본문/셀) 안의 연속 문단만 지원합니다. 표 안의 표 행 반복은 됩니다.
- 텍스트 상자·도형 안 텍스트는 DOCX 본문에 포함된 경우만 처리합니다. HWPX의 머리글이 별도 파일에 있는 비표준 문서는 처리하지 않습니다.

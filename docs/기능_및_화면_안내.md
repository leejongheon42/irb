# 기능 및 화면 안내 (v4.0 연구자용)

연구자가 IRB 제출 서류를 자동으로 완성하고 제출 전에 점검하는 도구입니다. 심의는 병원 e-IRB에서 진행되며, 이 시스템에는 위원회(심의·회의·결정) 기능이 없습니다.

- 데모 계정: `researcher`, `researcher2`(연구자), `admin`(관리자 = 연구지원 담당, 기관 설정)

## 1. 전체 흐름

```
① 과제 정보 입력 / 기존 계획서 가져오기(AI 인식)
② 제출 서류 패키지 → 자동 완성(초안·서류 작성·점검) → 자동 교정 → e-IRB 업로드용 ZIP
③ e-IRB에 올린 뒤 '제출 기록'
④ 심의 대기 → IRB 결과(승인·시정승인·면제·부결) 입력 또는 보완 요청 붙여넣기
⑤ 보완 대응(답변 초안·보완 답변서) → 재제출 패키지 → 재제출 기록
   승인 후: 변경 준비 / 지속심의 / 종료보고, 만료 60·30·7일 전 알림
```

## 2. 화면

### 공통
| 화면 | 주소 | 내용 |
|---|---|---|
| 내 연구 현황 | `/` | 작성·보완 중 / 심의 대기 / 보완 요청 받음 / 60일 내 만료 건수, 과제별 다음 할 일, 최근 알림 |
| 연구과제 | `/protocols` | 내 과제 목록(관리자는 전체) |
| 새 과제 | `/protocols/new` | 기본정보·연구내용·데이터·개인정보 보호·동의·이해상충 + 기관 추가 항목. 저장하면 패키지 화면으로 이동 |
| 기존 계획서로 시작 | `/protocols/import` | 다른 병원 양식 계획서(PDF·DOCX·HWPX·HWP)에서 항목 추출 → 새 과제 초안 |

### 과제 상세 `/protocols/{id}`
- **단계 표시줄**: ① 과제 정보 → ② 서류 자동 완성·점검 → ③ e-IRB 제출 기록 → ④ 심의 대기 → ⑤ 결과·보완 대응
- **IRB 결과 입력 / 보완 요청 등록**: 제출 기록 후 표시됩니다. 보완 요청문은 번호·글머리 기준으로 항목이 자동 분리됩니다.
- **탭**
  - **개요**
  - **IRB 사전점검**: 예상 심의유형, 위험도, 동의 면제 요건, 필요 서류, 검토 의견별 관련 근거, 유사 과제·과거 IRB 결과. 이 탭에서 e-IRB 제출 기록도 합니다.
  - **서류함**: 현행본, 점검 결과, 버전·비교·미리보기, 여러 파일 올리기, 서류 하나씩 자동 작성
  - **제출 이력**: 제출 구분, 접수번호, 예상 유형, IRB 결과, 변경 대비표
  - **연구팀 메모**
  - **기록**

### 제출 서류 패키지 `/protocols/{id}/package`
- **필요 서류 목록**: 이번 제출 구분 기준입니다. 서류마다 준비 방법(자동 작성 / 웹 서식 / 직접 올리기), 현행본, 점검 결과(C·M·m), 갱신 필요 여부가 표시됩니다.
- **한 번에 자동 완성**: 빈 서술 항목 초안, 서류 자동 작성(기관 서식 우선·DOCX), 전체 점검을 한 번에 실행합니다. 다시 작성·AI 사용 여부를 선택할 수 있습니다.
- **e-IRB 업로드용 ZIP**: 번호·서류명·버전 파일명과 제출 서류 목록·점검 요약이 들어 있습니다.
- **과제 정보 사전점검**: 서류 이전 단계인 과제 입력값 자체의 문제를 보여 줍니다.

### 서류 품질 점검 `/qc`, 결과 `/qc/{id}`
- **빠른 점검**: 파일 여러 개 업로드, 과제 정보 대조(선택), AI 심층 분석(선택), 샘플 체험
- **결과 화면**
  - 점수·PASS/FAIL, Critical·Major·Minor 건수, 3단계 스캔 상태
  - 점검한 서류(판별한 종류·파일명 버전)
  - 이슈 목록(근거·권고·자동 교정 문구)
- **자동 교정**: 이슈를 선택하고 글꼴 통일 여부를 정하면 변경 추적본과 수정 완료본을 만듭니다. 과제 서류는 새 버전으로 저장한 뒤 다시 점검합니다.
- 상세: [서류점검.md](서류점검.md)

### 보완 대응 `/protocols/{id}/revision`
- 항목마다 다음을 보여 줍니다.
  - 답변: 표준 문안 또는 AI 초안, 수정 가능
  - 고칠 서류·과제 항목
  - 관련 법령·가이드
- 보완 답변서(보완 대비표)를 자동 작성·첨부한 뒤 재제출 패키지로 이동합니다.

### 도움 도구
| 화면 | 내용 |
|---|---|
| 서식 자료실 `/doc-templates` | 기관 서식을 빈 양식 또는 내 과제로 채운 상태로 내려받기 |
| 관련 규정·사례 검색 `/knowledge`, 근거 질의응답 `/knowledge/ask` | 법령·지침·FAQ·보완 가이드·기관 SOP·과거 IRB 결과와 보완 요청 사례(본인 과제만, 관리자는 기관 전체) |
| 대상자 수 사전 조회 `/feasibility` | CDW(OMOP)·데모 데이터 집계, 소규모 셀 억제 |
| 가명처리 도구 `/deid` | 추출 자료의 개인정보 탐지·가명처리·k-익명성 평가 → 처리 보고서(가명처리 계획서 근거) |
| AI 문서 분석 `/protocols/{id}/pipeline` | 업로드 서류의 인식·분류·개인정보 점검·정보 추출 결과 |
| 웹 작성 서식 `/protocols/{id}/online-forms` | 이해상충·서약서 등 기관 웹 서식(연구진 개인별) |

### 관리자(연구지원)
- 기관 프로필(기관명·IRB 연락처: 동의서 연락처에 사용)
- 기관 양식(신청서 추가 항목·웹 서식·양식 팩)
- 기관 서식(DOCX·HWPX 업로드·매핑)
- 사전점검 규칙, 지식 관리, AI·문서 자동화, 사용자 관리, 감사 로그

## 3. 자동 작성 서류

심의의뢰서, **연구계획서**, **연구대상자 설명문 및 동의서**(동의 취득 과제), 동의 면제 사유서, 심의면제 확인 신청서, 가명처리 계획서, 증례기록서/자료수집 항목표, 보안 서약서, 변경 대비표(변경 시), 참여기관 목록(다기관), **보완 답변서**(보완 요청 시).

병원 고유 서식이 활성화되어 있으면 그 서식에 채웁니다.

## 4. 제거된 기능 (v3 → v4)

IRB 측 기능은 모두 제거했습니다.
- 위원회 회의, 위원 배정·심의의견, 결정·통지서
- 가명처리 적정성(DRB) 검토, 결과 반출 심사, 자료 제공 계약·파기·처리기록 대장
- 성과지표·연간 운영실적, 서류 검토 대기열·승인 도장, CDW 승인 확인 API

IRB 결과는 연구자가 통지서를 보고 입력합니다.

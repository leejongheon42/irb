# 공용IRB 98개 시나리오별 서식·제출자료 대응표

확인일: 2026년 11월 14일. 첨부된 시나리오 1~98의 번호를 그대로 유지했습니다.

## 먼저 읽을 사항

- **각 시나리오의 ‘공통 A’, 연구계획서, 동의서, 별도 자료, 진행 중/종료 자료를 합쳐서 읽으시면 됩니다.** 진행 중 보고는 해당 사건이 발생하는 시점에 제출하며 신규 신청 때 모두 내는 것은 아닙니다.
- 공용위원회 표준운영지침 **ver.5.5(공개 게시 2025-08-11)**와 현재 국가생명윤리정책원 공개 안내, 공개 서식의 실제 본문·첨부 지시를 대조했습니다. [S1~S4]
- **‘권고’는 공용위원회명이 서식 본문에 확인되는 권고서식입니다.** 제38·39·40·41·43·44·45·46·47호의 표지를 확인했습니다. 자료실의 번호만으로 일반 기관위원회용과 공용 전용을 추정하지 않았습니다.
- **‘구 별지’는 공개 보관된 예전 서식의 번호입니다.** 해당 신청/보고가 현재 e-IRB 입력으로 처리되면 별도 HWP까지 중복 제출해야 한다는 뜻이 아닙니다. 현재 로그인 후 자료실·신청화면의 최신 파일명/첨부 요구까지는 확인하지 못했으므로, 구서식의 번호·자가점검표를 현행 필수 파일로 단정하지 않았습니다.
- ‘별도 준비자료’에는 ① 공용IRB 제출 근거가 확인된 자료, ② 해당 조건에서 요구되는 증빙, ③ 연구 수행/자료 반출을 위해 기관에서 확보할 허가가 포함됩니다. **③의 모든 문서를 공용IRB에 일률적으로 첨부하라는 의미는 아닙니다.** 관련 근거를 계획서에 설명하고 위원회가 요청하는 증빙을 제출합니다.
- 심의면제와 서면동의면제, 연구 수행 예정기간 변경과 승인유효기간 연장, 검체 제공과 보존 불가에 따른 이관을 각각 구분했습니다.
- 시나리오의 절차·승인 결과를 가정해 서류를 연결한 자료입니다. 현재 조건만으로 전용 절차의 필수서류를 정할 수 없는 40~48번 등은 그 한계를 개별 표시했습니다.

### 연구자가 제출할 서류에 넣지 않은 것

연구심의 접수확인서, 심의비청구서, 결과통지서, 심의면제확인서, 연구계획/지속심의/종료/이상반응/위반이탈 **심사서**, 제공·폐기/이관 **심사서**, 평가점검표, 현장점검결과통지서는 위원회·사무국·심사자가 작성하거나 발행하는 문서입니다. 연구자가 필요한 증빙으로 기존 승인통지서를 첨부하는 경우와 직접 양식을 작성하는 경우는 구분했습니다.

## 3. 시나리오 1~98 상세 대응

아래 ‘진행 중·종료’는 원문 경로에 있는 사건에 따라 붙는 서류입니다. 같은 연구라도 보완·이상반응·변경이 실제 발생하지 않으면 해당 사건의 보고자료를 신규 때 미리 낼 필요는 없습니다.
